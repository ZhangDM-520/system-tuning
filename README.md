# system-tuning

Unified system tuning for this machine: eco/power policy, benchmark methodology + studies, filesystem maintenance & XFS tuning.

## Directory index

| Path | Contents |
|------|----------|
| `eco/` `lib/` `state/` `tests/` | eco apply convergence machinery + managed live config |
| `benchmarks/` | System-Tuning-Benchmarks content, incl. methodology + studies |
| `docs/` | Doctrine, decisions, findings + FS docs |
